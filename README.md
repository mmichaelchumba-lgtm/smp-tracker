# SMP Tracker

A Python-based personal performance tracking project developed as part of my Python and AI Masterclass.

## Project Purpose

The goal of this project is to develop a tool for tracking daily performance and building practical programming skills using Python.

## Current Features

- Python project setup and execution.
- Starter tracker script.
- Weekly report function.
- Git version control and GitHub integration.

## Project Files

- `Tracker.py` - Main starter script.
- `report.py` - Weekly report function.
- `conflict_practice.py` - Git merge conflict practice.
- `notes.txt` - Project notes.

## Requirements

- Python 3
- Visual Studio Code (recommended)

## How to Run

Open the project folder in your terminal and run:

```bash
python Tracker.py
```

```text
SMP Tracker is running successfully
```
